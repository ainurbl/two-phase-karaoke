# Two-Phase Karaoke

Небольшой Python-скрипт для создания караоке-видео в два независимых шага:

1. `transcribe` берёт только акапеллу и получает черновик текста с таймингами в SRT.
2. `render` берёт только минусовку и отредактированный SRT, поэтому в готовом видео нет вокала.

Текст и время строк можно править в любом редакторе субтитров или обычном текстовом редакторе между фазами.

## Установка

Нужны Python 3.10+, FFmpeg и `whisper-cli` из [whisper.cpp](https://github.com/ggml-org/whisper.cpp). На macOS:

```bash
brew install ffmpeg whisper-cpp
python3 -m pip install -r requirements-render.txt
```

Для первой фазы также скачайте GGML-модель Whisper, например английскую `ggml-base.en.bin`, и сохраните её вне репозитория.

## 1. Акапелла → SRT

```bash
python3 two_phase_karaoke.py transcribe vocal.mp3 lyrics.srt \
  --model /path/to/ggml-base.en.bin --language en
```

Результат — `lyrics.srt` и текстовый файл `lyrics.txt`. Это черновик: проверьте слова и тайминги перед сборкой ролика.

## 2. Минусовка + SRT → MP4

```bash
python3 two_phase_karaoke.py render instrumental.mp3 lyrics.srt karaoke.mp4 --lead-ms 1000
```

Во второй команде нет вокальной дорожки: в MP4 кодируется только минусовка. Видео одновременно показывает две строки: выделенную текущую и приглушённую следующую, а также волновую форму инструментала.

`--lead-ms 1000` показывает строку за секунду до её таймкода — это стандартный режим для караоке. Исходный SRT при этом не меняется. Для другой величины опережения укажите своё число, а `--lead-ms 0` оставит точное совпадение с SRT. Добавьте `--overwrite`, если нужно перезаписать существующий SRT или MP4. Параметр `--crf` управляет качеством видео: меньше значение — выше качество и размер файла.

## Формат SRT

```srt
23
00:01:12,000 --> 00:01:15,200
Текст строки
```

Можно менять текст, делить строки и поправлять время. Не допускайте пересечений временных отрезков: скрипт остановится с понятной ошибкой.
